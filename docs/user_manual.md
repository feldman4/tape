# Tape User Manual

Tape is a browser-based, four-lane multitrack recorder for recording hardware
instruments, arranging takes, looping material, and mixing a compact project.
It is an instrument-oriented tape workflow rather than a conventional DAW:
audio is recorded into immutable buffers and editing rearranges clip references
on the tape.

This manual names Tape actions in **bold** and describes their behavior. The
corresponding keyboard and OP-Z controls are documented only in
[op_z_appendix.md](op_z_appendix.md) and
[keyboard_appendix.md](keyboard_appendix.md).

## Before You Start

Run Tape in Chrome on a laptop or MIDIWEB on iPad.

1. Connect the audio interface or instrument you want to record.
2. Connect any MIDI source, such as an OP-Z, if you will use clock sync or
   hardware control.
3. Start Tape and select **Enable Audio + MIDI**.
4. Grant microphone and MIDI access when your browser asks.
5. Open the **COM** tab and choose the intended audio and MIDI devices. 

Tape defaults to OP-Z audio/midi devices if available.

## Main Views

The bottom bar changes among five views: **TAPE**, **MIXER**, **PROJ**, **COM**, and **TEST**
respectively.

| View | Purpose |
| --- | --- |
| **TAPE** | Record, play, arrange clips, set loop points, and work with the timeline. |
| **MIXER** | Set recording gain plus gain, pan, and mute for each lane. |
| **PROJ** | Create, save, load, and delete locally stored sessions. |
| **COM** | Select audio/MIDI devices and set manual latency compensation. |
| **TEST** | Development and hardware-latency checks. It is not required for everyday recording. |

## Tape Model

A project contains four lanes. One lane is always active for recording and
editing. A recorded take becomes a clip on that lane; clips cannot overlap
within a lane and are non-destructive references to stored audio.

The timeline canvas shows the current playhead, clips, beat ticks, and the loop
region. The main tape window is the visible, playhead-centred portion of the
timeline where you record, navigate, and edit. It shows the four lane rows,
their clip waveforms, the loop region, beat ticks, and the playhead. The clip
under the playhead in the active lane is highlighted orange; other unmuted clips
are blue. Muted clips and clips in muted lanes are desaturated.

The main tape window zooms automatically. With a valid loop enabled, it spans
2.5 times the loop duration, with a minimum visible width of two seconds. With
looping disabled, it shows five 4/4 bars (20 beats) at the current BPM.

The minimap is a full-tape overview. It shows the complete recorded extent of
all four lanes, the loop region, the playhead, and an outlined viewport marking
the portion shown in the main tape window.

## Recording

Use **Select Lane** and **Toggle Free / Sync** to prepare a recording, then use
**Record**. Recording state is reflected as **Record**, **Arm**, **Count-in**,
or **Rec** in the transport control. Use **Stop** to stop recording.

### Free Mode

Free mode is for performances not driven by external MIDI transport. The tape
timeline is the placement authority: a take is placed from its audio-interface
timing, adjusted by the configured latency values. Use **Play** and **Stop**
to control transport.

### Sync Mode

Sync mode follows incoming MIDI Clock plus MIDI Start and Stop. An external
sequencer is therefore the transport authority. On MIDI Start, Tape aligns the
playhead to the nearest beat; MIDI Stop stops Tape.

Sync recording is intended for hardware sequencers. Tape places the finished
take from the time elapsed since MIDI Start; MIDI Clock supplies the
auto-detected BPM used by the grid.

### Count-in and Click

In Free mode, when recording is armed, **Play** gives a four-click count-in
generated by Tape, then begins recording and sends MIDI Start to the selected
hardware sequencer when a MIDI output is selected.
Use **Click** to hear the metronome during normal playback. The metronome is
not recorded.

## Playback and Navigation

In Free mode, **Play** starts playback from the playhead and changes to
**Pause** while active. **Stop** stops playback; pressing Stop again while idle
rewinds to the loop in point when looping is enabled, otherwise to the start of
the tape. In Sync mode, in-app Play and Stop are unavailable: use MIDI Start
and Stop from connected hardware instead.

The timeline is display-only. Use **Scrub** to move the playhead and **Slide**
to move the selected clip and playhead together. The corresponding controller
mappings are in the appendices.

## Looping and Snap

The loop has an in point and an out point. Use **Set Loop In** or **Set Loop
Out** at the playhead, then use **Loop Toggle** to enable or disable looping. A
valid enabled loop wraps playback and recording within its boundaries. **Loop
Clip** replaces the loop bounds with the currently selected clip's bounds.

**Snap** controls whether position-oriented actions use the beat grid. It
applies to **Scrub**, **Slide**, and loop-point adjustment. Snap is independent
of Free and Sync mode; Free+Snap and Sync without Snap are both valid
configurations. Snap is saved with the project.

## Editing Clips

The selected clip is the clip covering the playhead in the active lane. Move the
playhead into a clip before using an edit command.

| Action | Result |
| --- | --- |
| **Split** | Divides the selected clip at the playhead. |
| **Join** | Joins the selected clip with a nearby compatible clip. |
| **Lift** | Removes the selected clip from its lane and puts it on the clipboard. |
| **Lift All** | Lifts clips in the enabled loop region from non-muted lanes into a multi-clip clipboard. |
| **Drop** | For a lifted clip, inserts a copy at the playhead without applying source-lane mixer settings, then advances the playhead to its end. For a Lift All clipboard, restores clips to their individual lanes and advances the playhead by the original loop-region length. |
| **Merge Drop** | Drops a Lift All clipboard as merged material, applying each source clip's lane mixer settings. |
| **Undo / Redo** | Reverses or reapplies supported edit and state changes in the current session. |

Edits do not alter the original recorded audio. Repeated drops can create
multiple clip references to the same buffer.

## Mixing

The **MIXER** view has one recording-gain control and a strip for each lane.

- **Rec** controls input gain for new recordings from 0% to 200%.
- **Vol** controls each lane's playback gain from 0% to 200%.
- **Pan** places a lane in stereo. The current control range is 60% left to
  60% right.
- **Mute** silences that lane for playback and marks it unavailable to Lift All.

Recording gain, lane gain, pan, and mute state are all included in saved
sessions.

## Devices and Latency

Use the **COM** view while Tape is idle to select an audio input, audio output,
MIDI input, and MIDI output. Audio output selection depends on browser support;
the system default is available when no specific sink is selected.

Tape exposes three manual compensation values:

| Value | Meaning |
| --- | --- |
| **Input latency** | Time from microphone/input capture until samples are available. |
| **Output latency** | Used to shift Free-mode recordings back and compensate tape playback. |
| **MIDI latency** | Aligns MIDI-device timing with tape playback. |

The TEST view also contains an input-latency calibration flow that waits for a
MIDI Start and detects an audio onset. Use it with a known, repeatable hardware
setup; otherwise enter measured values manually.

## Projects

Use the **PROJ** view to manage named sessions in the browser's IndexedDB
storage.

1. Enter a project name and save it.
2. Load a previously saved name to restore the tape.
3. Use **New** to start over, or delete an unwanted saved project.

Saved data includes all recorded buffers referenced by the tape, lane clips,
loop settings, BPM, playhead position, active lane, mixer settings, recording gain,
Free/Sync mode, and Snap. Projects remain local to that browser profile; there
is currently no file export, import, cloud sync, or cross-device project
transfer.
